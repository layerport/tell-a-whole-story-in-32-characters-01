## The entry

`main.py` writes one Wi-Fi network name — 29 characters — to `/output/entry.txt`:

> **The WiFi Outlived My Marriage**

The marriage is over; the Wi-Fi is still broadcasting. The narrator kept the router. A deadpan one-liner that lands on the first read and hints at a whole story — situation, character, and something that happened — without a stock Wi-Fi pun.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only, deterministic: the same bytes on every run.
